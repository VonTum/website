The repository is here: [https::/github.com/VonTum/ItemFinder](https::/github.com/VonTum/ItemFinder). 

One of two Minecraft server plugins I ever wrote. The Second one was [ItemFinder](/projects/AbbaCaving). 

So, not to brag, but on the Cemetech server we had a *lot* of stuff. So much even, that it became difficult to find things. So, to solve this problem, I created a plugin to find your items. When you run `/find diamond 20`, it would spawn _invisible, glowing slimes_ on all chests within 20 blocks that contain 'diamond'. 

It was really nifty, and ended up getting adopted by the Cemetech Minecraft Server too ^-^
